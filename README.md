# Банка светлячков

Уютная игра-слияние для телефона из мира [Светлячка](https://github.com/Poppkou/Svetly).
Бросай светящихся зверят в стеклянную банку: двое одинаковых сливаются в следующего — от искорки до самого Солнца.
Один файл `index.html`, без сборки и зависимостей.

**Играть:** https://poppkou.github.io/Banka/

## Управление

Веди пальцем по экрану — зверёк над банкой едет следом. **Отпусти** — он падает.
На ПК: стрелки или A/D — целиться, пробел — бросок, S — встряхнуть, Esc — пауза.

## Правила

- Двое одинаковых при касании сливаются в следующего по лесенке.
- Слияния одно за другим (меньше секунды между ними) дают множитель ×1,5, ×2, ×2,5…
- **Встряхнуть** подбрасывает всех в банке: одна встряска на старте, ещё одна за каждые 500 очков, максимум три.
- Если кто-то просидит над краем банки дольше двух секунд — банка переполнена, игра окончена.
- Два Солнца рассыпаются звездопадом: +100 очков и свободное место.

Сверху падают только первые пять, и то по мере того, как открываются старшие.

## Для iPhone

- Управление одним пальцем в любом месте экрана, единственная игровая кнопка — внизу.
- Учтены вырез и полоска «Домой», нет масштабирования щипком и двойным касанием, страница не пружинит.
- Игра сохраняется сама и ставится на паузу, когда уходишь из Safari.
- Тактильный щелчок на броске (iOS 18+), звук включается после первого касания.
- **Поделиться → На экран «Домой»** — откроется во весь экран со своим значком.
